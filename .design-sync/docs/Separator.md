Línea divisoria de 1px en color `border`. Usa `orientation="vertical"` dentro de filas flex (necesita altura definida en el contenedor).

## Composición

```jsx
<div className="flex items-center gap-3 text-sm">
  <span>12 sesiones</span>
  <Separator orientation="vertical" className="h-4" />
  <span>racha de 5 días</span>
</div>
```
