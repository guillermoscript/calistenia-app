Etiqueta compacta de estado o categoría. Es donde el lima sí es correcto: marca completado o activo. `variant="secondary"` para categorías neutras, `destructive` para fallos.

## Composición

```jsx
<Badge className="bg-lime text-lime-foreground">Completado</Badge>
<Badge variant="secondary">Tirón</Badge>
<Badge variant="outline">Intermedio</Badge>
```
